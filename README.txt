B.NICKOLE — CLOUDFLARE PAGES SITE

UPLOAD
1. Sign in to Cloudflare and open Workers & Pages.
2. Create a Pages project and choose Upload assets / Direct Upload.
3. Upload b-nickole-final-site.zip.
4. Select Deploy.

EDIT THE LINKS
Open links.js and replace each # with the correct destination URL.
The five category cards and Instagram link are intentionally inactive until
their URLs are added.

IMPORTANT FILES
- index.html: page content and category order
- styles.css: colors, typography, spacing, and responsive layout
- links.js: Instagram and category destinations
- assets/images: optimized logo, favicon, and category photographs
